\caption{\encore{} values: every value and heap header is one 32-bit word, \code{[payload:16 | meta:8 | typ:8]}. Integers, functions, and nullary constructors never allocate; heap addresses are 16-bit word indices. A heap object is a GC header followed by its contents: a closure header and the captured values, the fields of a constructor, or a bytes header and the bytes, 4 per word. A value points at its object's GC header, so \code{FIELD $i$} reads word $\mathit{addr} + 1 + i$.}
